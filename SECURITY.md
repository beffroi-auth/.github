# Security policy

A vulnerability in any repository of beffroi-auth is reported privately, through the [security advisories](https://github.com/beffroi-auth/beffroi/security/advisories/new) of the monorepo. Do not open a public issue, do not discuss it in a pull request.

The repositories of the packages and of the application are read-only mirrors of [beffroi-auth/beffroi](https://github.com/beffroi-auth/beffroi): a report about `beffroi/core`, `beffroi/oidc`, `beffroi/saml`, `beffroi/xml-security`, `beffroi/saml2-model`, `beffroi/saml2-bindings`, `beffroi/tui` or the application goes there.

The scope, the time to an acknowledgement and the supported versions are those of the [security policy of the monorepo](https://github.com/beffroi-auth/beffroi/security/policy).
